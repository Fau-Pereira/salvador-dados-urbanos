# Salvador Urban Data Platform

Plataforma de Engenharia de Dados Urbanos que integra
indicadores estatísticos e dados geoespaciais oficiais.

## Tecnologias

- Python
- PostgreSQL
- PostGIS
- Docker
- SQL
- GeoPandas

## Arquitetura

O projeto utiliza quatro camadas:

1. Raw
2. Staging
3. Core
4. Analytics

## Status

Etapas 1 e 2: configuração do ambiente e modelagem inicial.

Próxima etapa: desenvolvimento dos pipelines de ingestão
de dados do IBGE e das malhas territoriais.
